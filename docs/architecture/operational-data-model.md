# Modelo operacional futuro

A fundação visual do cliente web não define nem antecipa o schema dos módulos operacionais.

Antes da criação de migrations para clientes, fornecedores, produtos, estoque, vendas, financeiro e demais áreas, o modelo definitivo será revisado visualmente em draw.io. O artefato previsto será `docs/database/erp-database.drawio`, criado apenas quando houver um modelo aprovado — não existe arquivo vazio ou provisório nesta etapa.

Até essa revisão, as páginas desses módulos representam somente estrutura de interface e não realizam persistência, chamadas para endpoints inexistentes ou armazenamento local de dados.
